# Mahalakshmi & Surya Prakash · A Sacred Beginning

A self-contained static wedding invitation with an interactive temple entrance, responsive layouts, keyboard-accessible event selection, wedding countdown, calendar downloads, optional music, photo viewing and invitation sharing.

All in-page images, fonts and audio are bundled in `assets`. The site has no third-party scripts or runtime package dependencies. This version is laid out for the existing GitHub Pages root deployment. The CNAME keeps the existing wedding domain. The original Google Maps directions and event information were preserved from the supplied wedding repository.

## Content

- Reception: 10 November 2026, 7 PM onwards, Rahul Convention Hall.
- Muhurtham: 11 November 2026, 9:21–9:51 AM IST, Sri Maha Ganapathi Temple.
- Bride: Mahalakshmi A, daughter of Armugam R and Shanthi A.
- Groom: Surya Prakash S, son of Sugendra C and Amudha S.

The temple courtyard and wooden door images are original generated invitation artwork, not photographs of the listed venues. The couple photograph, music and existing social card came from the supplied repository. All styling and interactions are implemented in `styles.css` and `app.js`. Update title, dates, family details and map links in `index.html`. Update the countdown date in `app.js` and the calendar files together if the ceremony changes.

Music starts only after an explicit guest action. Entrance replay is available in the footer. The entrance can be skipped and honors reduced-motion preferences. No RSVP form or data collection is used.
